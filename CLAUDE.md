# PlantHub

## Handoff notes (every session)

Several sessions work on this repo in parallel, and long sessions get retired. Each session keeps a handoff note so a fresh one can pick up cheaply.

- At the start of a session, read `docs/handoffs/` before exploring anything else. Read your own lane's note in full; skim the others only if your task touches them.
- Keep your lane's note at `docs/handoffs/<lane>.md` current: update it after each commit and before stopping work. Follow the template in `docs/handoffs/README.md`.
- Edit only your own lane's note.
