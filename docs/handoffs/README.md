# Handoff notes

One file per session lane (for example `website-v2.md`, `grower-side.md`, `specs.md`). Each note lets a fresh session continue the work without the old conversation.

A new session reads the notes here first, instead of re-exploring the project.

## Rules

- Each session edits only its own file, so parallel sessions never overwrite each other.
- Update the note after each commit and before stopping work, not just at the end.
- Keep it under 150 lines. Replace stale content; don't append a diary.
- Write "unsure" where unsure. Don't guess.

## Template

```
# <Lane name>
Last updated: <date>

## Lane
What this session owns, in one sentence.

## Done
What's finished and committed (with commit IDs).

## In progress
Anything half-done, uncommitted, or on a branch, and its exact state.

## Decisions
What was decided and why, including options rejected.

## Open questions
Anything waiting on Kendrick.

## Next steps
In order, specific enough to start immediately.

## Gotchas
Anything surprising that would trip up a newcomer.

## Key files
The handful of files that matter, one line each.
```
